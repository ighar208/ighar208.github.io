About Me

Halo! Nama saya Muhammad Fattah Giri Gharsina, siswa SMKN 5 Malang, kelas 11 PPLG 2. Sejak kecil, saya selalu menyukai dunia olahraga dan aktivitas yang penuh semangat. Saya percaya bahwa olahraga bukan hanya sekadar hobi, tetapi juga cara untuk melatih kerja sama, disiplin, dan semangat pantang menyerah. Saya memiliki ketertarikan besar di bidang sepak bola, karena saya senang bermain bersama teman-teman dan merasakan semangat kompetisi di lapangan. Bagi saya, sepak bola bukan hanya permainan, tetapi juga tempat untuk mengembangkan kemampuan, menjaga kesehatan, dan menciptakan banyak pengalaman seru.

Selain bermain bola, saya juga memiliki hobi berolahraga dan mencoba hal-hal baru yang menantang. Bermain sepak bola adalah dunia di mana saya bisa melatih kerja sama tim, strategi, dan semangat juang. Saya sering bermain bersama teman-teman di lapangan sekolah maupun lingkungan sekitar. Saya juga suka mempelajari hal baru, terutama yang berhubungan dengan teknologi, luar angkasa, dan pengembangan diri. Semangat untuk terus belajar adalah bagian penting dalam hidup saya, dan saya percaya bahwa dengan usaha dan latihan yang konsisten, saya bisa meraih cita-cita yang besar. Di masa depan, saya ingin menjadi seorang astronot agar bisa menjelajahi luar angkasa, mempelajari planet-planet, dan membawa kebanggaan bagi Indonesia di dunia penerbangan antariksa.

My Projects

Landing Page Dashboard Sekolah Landing page ini merupakan dashboard sistem informasi sekolah yang menampilkan data penting seperti jumlah siswa, guru, absensi, dan rata-rata nilai. Terdapat menu navigasi untuk mengelola data sekolah seperti siswa, guru, jadwal, nilai, dan absensi. Selain itu, tersedia grafik dan diagram untuk mempermudah pengguna melihat statistik dan perkembangan data sekolah secara visual.

Landing Page API Postman Guide Landing page ini berisi panduan dasar REST API menggunakan Postman dengan metode GET, POST, PUT, dan DELETE. Pada tampilan utama dijelaskan fungsi metode GET untuk mengambil data dari server tanpa mengubah data. Desainnya modern dan informatif sehingga memudahkan pengguna memahami konsep dasar API dan penggunaan Postman.
